# iOS 字重校准记录（2026-10-03）

- 设备：iPhone 模拟器，iOS 26.5（原生 SwiftUI/UIKit）vs Flutter 3.41.9（Impeller）
- 样本：22pt 纯黑「Flutter 字重 Font Weight」，同宽截图（746px），逐行墨迹密度
- 原生侧中间值实现：`UIFont.systemFont(ofSize:weight: UIFont.Weight(rawValue:))`

  w700=0.4, w800=0.56, w900=0.62，中间值在相邻锚点间线性插值）

## 结论

1. Flutter(iOS) 全量程偏细；w300~w600 稳定低 6~7pp（约原生 0.72~0.78）。
2. Flutter 吸附对：w100=w150、w200=w250、w700=w750、w600≈w650；
   原生中间值基本单调可插值。
3. 高字重 Flutter 档位稀疏：实际 Plateau 约在 w650(.23) / w800(.30) / w900(.39)，
   w800→w850 有非单调回落；原生 w850 即触顶。
4. 最准锚点：原生 w300 ≈ Flutter w450（gap 0.01pp）；原生 w400 ≈ Flutter w600。

## iOS 补偿映射（写在 lib/utils/lj_define.dart）

经历两版迭代，**当前采用 v2（视觉走查保守版）**；v1 仅作实测参考保留。

### v2 · 当前采用（2026-10-04，视觉走查后）

补偿跨度整体比 v1 收窄一档，更贴近原档，避免过补偿观感。

|---|---|---|
| ultralight w100 | 200 | 低端就近 |
| thin w200 | 300 | |
| light w300 | **350** | 350 实际偏向 400，作为轻量加档 |
| regular w400 | **450** | 450 偏 400，补偿温和 |
| medium w500 | **600** | |
| semibold w600 | **700** | |
| bold w700 | **700（不补偿）** | 与 semibold 视觉等价；需要更粗可改 900 |

注意：v2 下 semibold 与 bold 在 iOS 均渲染为 w700，无层级差。
`quickText`/`textStyle`/`quickGradientText` 的默认字重也由 medium 改为 regular。

### v1 · 实测严格版（2026-10-03，已弃用）

按墨迹密度"最近匹配"得出，补偿跨度最大：

| 设计（原生） | v1 取值 | 说明 |
|---|---|---|
| ultralight w100 | 200 | 低端吸附，就近 |
| thin w200 | 300 | |
| light w300 | 450 | 实测近乎重合（gap 0.01pp） |
| regular w400 | 600 | gap ≈ −0.7pp |
| medium w500 | 750 | 750 实际等于 700；严格最近应为 800(+2pp) |
| semibold w600 | 800 | gap ≈ +0.4pp |

v1 弃用原因：视觉走查认为整体补偿偏重；且 medium(750=700)、semibold(800)、
bold(900) 在高字重稀疏档位上层级跳变生硬。

其他平台一律标准值（w100…w700），两版映射均仅对 iOS 生效。
